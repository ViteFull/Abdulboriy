# Contributing to UzDevKit

Thanks for considering a contribution!

## Before you start

- Check existing issues so work is not duplicated.
- For a major feature, open an issue first to discuss the idea.
- Keep the app lightweight and dependency-free where practical.
- Preserve the privacy-first approach: process user input in the browser.

## Pull request checklist

- [ ] The change solves one clear problem.
- [ ] The interface works on mobile and desktop.
- [ ] Inputs are validated and errors are understandable.
- [ ] No user input is sent to an external server.
- [ ] README is updated when a feature changes.

## Local testing

Open `index.html` in a modern browser and test the changed tool with valid and invalid input.
