# Abdulboriy — Developer Portfolio

A responsive bilingual (English / Uzbek) portfolio built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive dark interface
- English / Uzbek language switch
- GitHub profile avatar and links
- Automatically loads public repositories from the GitHub API
- About, skills, projects and contact sections

## Run locally
Open `index.html` in a browser.

## Live source
This portfolio is stored in the `portfolio/` directory of the repository.
